About this chart

Each point is the number of times {{ analysis.team_name }}'s hitters reached base in one completed game: hits plus walks plus hit-by-pitch. Reached-on-error and fielder's choice are not counted, since neither is a hit, a walk, or a hit-by-pitch. The {{ rolling_average_label|lower }} covers that game and the {{ analysis.rolling_window - 1 }} games before it, and early-season points use every game played so far. The dashed line is the team's average across the completed games currently stored for this season. A higher or lower value describes how often the team put a runner on base; it is not automatically better than a club doing other things well, and neither direction is labelled good or bad here.

{% if league_comparison %} The dotted line is MLB overall. {% endif %} {{ league_comparison_note }} {% if league_comparison %} A positive vs MLB value means {{ analysis.team_name }} put runners on base more times per game than MLB overall across the stored season, and a negative value fewer. It is descriptive context, not a measure of significance. {% endif %}

What Baserunners/Game does not tell you

This is a per-game count, not a rate. It is not the same statistic as on-base percentage (OBP), which divides the same numerator by plate appearances. Plate appearances are not currently persisted, so this page does not estimate OBP.

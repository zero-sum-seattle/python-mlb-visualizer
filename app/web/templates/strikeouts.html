About this chart

Each point is the number of times {{ analysis.team_name }}'s hitters struck out in one completed game. These are batting strikeouts, not strikeouts recorded by the team's pitchers. The {{ rolling_average_label|lower }} covers that game and the {{ analysis.rolling_window - 1 }} games before it, and early-season points use every game played so far. The dashed line is the team's average across the completed games currently stored for this season.

A higher or lower value describes how many times hitters struck out in each stored completed game. It is not labelled good or bad here: whether more batting strikeouts matter depends on the question being asked and on what else the offense is doing.

What K/Game does not tell you

Strikeouts per game is a count, not a rate. Games contain different numbers of plate appearances: extra innings, long innings, and games shortened by weather all change how many chances hitters got. A game with more opportunities can show more strikeouts without the hitters striking out any more often.

Strikeout rate (K%), which divides strikeouts by plate appearances, answers the opportunity-adjusted version of this question and would be the better measure for it. It is deferred until plate appearances are persisted; this page does not estimate it.
